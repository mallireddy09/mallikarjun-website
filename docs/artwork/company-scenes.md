# Company scene references

These small SVG illustrations represent public company products, rather than specific contributions or endorsements. They use native SVG shading for depth and CSS motion; no remote assets or runtime requests are needed.

- NVIDIA: Graphics-card illustration with three spinning cooling fans, heatsink fins, PCIe contacts, and animated parallel workloads. Reference: https://developer.nvidia.com/cuda
- Microsoft: Azure cloud connected to detailed server racks, with staggered activity lights and flowing data. Reference: https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-azure
- The Home Depot: a detailed orange storefront and home, with a moving orange delivery van with rounded bodywork, reflective glass, chrome details, and rotating wheels. Reference: https://www.homedepot.com/c/delivery
- Uber: a black luxury sedan with rotating wheel spokes follows a blue route directly inside an Apple Maps–style illustrated map, turning with the road and arriving at a destination pin. The map is a local SVG illustration, not a live Apple Maps integration. Reference: https://help.uber.com/en-GB/riders/article/how-to-request-a-ride?nodeId=e9862b49-81c6-4c6a-a9d3-3c05bf42e82e

References checked October 25, 2026. Previews open on hover or focus, and toggle on touch. CSS disables all scene animations for reduced motion.
